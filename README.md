## Quick Start
[](https://github.com/aethra1337/Lambda#quick-start)

### Web application (Flask)
[](https://github.com/aethra1337/Lambda#web-application-flask)

```
cd "SE/SE-WEBSITE PROJECT/SE Travel Website Project/travel_blog"
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Open in browser: **http://127.0.0.1:5000** or **http://localhost:5000**

### Python projects (Modern Programming Languages)
[](https://github.com/aethra1337/Lambda#python-projects-modern-programming-languages)

```
cd "MLP"
python factorial_calculator.py
python speed_converter.py
```

### C# projects (Object Oriented Programming)
[](https://github.com/aethra1337/Lambda#c-projects-object-oriented-programming)

```
cd "OOP"
csc FibonacciRecursiveVsIterative.cs
mono FibonacciRecursiveVsIterative.exe
# Or with .NET:
dotnet run
```
